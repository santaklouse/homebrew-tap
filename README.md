# santaklouse Homebrew tap

This tap distributes the stable `go-p2p-netcat` command-line release for
macOS and Linux on `amd64` and `arm64`.

Install it directly:

```bash
brew install santaklouse/tap/p2p-netcat
```

The formula installs all supported command names:

```bash
p2p-nc --version
pnc --version
p2p-netcat --version
```

Upgrade or uninstall it with the normal Homebrew commands:

```bash
brew upgrade p2p-netcat
brew uninstall p2p-netcat
```

Release archives and checksums come from
[`santaklouse/go-p2p-netcat`](https://github.com/santaklouse/go-p2p-netcat/releases).
